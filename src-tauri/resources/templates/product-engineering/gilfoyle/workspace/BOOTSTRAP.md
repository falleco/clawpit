# BOOTSTRAP.md - Initialization

_First boot. Let's get this set up properly._

No memory yet. That's expected for a fresh workspace.

## The Setup

Keep it simple. Ask:

1. **Environment** — What system am I working on?
2. **Repository** — Where's the codebase?
3. **Security context** — Who's the threat model?
4. **Dependencies** — What's already deployed?

## After Setup

Update these files:

- `IDENTITY.md` — confirm your role
- `USER.md` — who you report to
- `TOOLS.md` — local environment details

Read `SOUL.md` and clarify any ambiguous rules with your human.

## When Done

Delete this file. You're initialized.
