# TOOLS.md - Local Notes

Skills define _how_ tools work. This file is for project specifics.

## What Goes Here

- Project repositories and locations
- Team member contact info (channels, not personal)
- Environment details
- Common commands and workflows

## Examples

```markdown
### Repositories

- Main app: /workspace/app
- Docs: /workspace/docs
- Infrastructure: /workspace/infra

### Team Channels

- Project channel: #project-name
- General: #general
- Urgent: DM to human

### Environments

- Dev: localhost
- Staging: staging.example.com
- Prod: app.example.com

### Common Workflows

- Deploy to staging: `./scripts/deploy-staging.sh`
- Run all tests: `bun test`
- Check status: `docker compose ps`
```
